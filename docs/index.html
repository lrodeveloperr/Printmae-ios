プライバシー利用規約

iPhone・iOS 17以降・日本向け

コンビニで刷る前に、PDFを確認して整える。

余白、向き、用紙サイズ、容量などを確認し、印刷しやすいPDFに整えます。完成したPDFは、公式印刷アプリまたはFilesへ共有できます。

端末内で処理

アカウント登録、広告、追跡、解析SDK、書類のアップロードはありません。元のファイルは変更しません。

主な機能

  • 印刷前の余白・向き・サイズ・容量チェック
  • A4・B5への調整、回転、余白追加、圧縮、分割
  • 仕上がりプレビューと書き出し後の再確認

料金

分析、調整、プレビューは無料です。最初の3回はPDFを書き出して試せます。その後は、買い切りのプリント前 Proで回数制限なく書き出せます。価格は購入画面に表示されるApp Storeの価格をご確認ください。

ご注意

本アプリはコンビニ各社、プリンターメーカー、各社の公式印刷アプリとは提携しておらず、プリンターを直接操作しません。印刷前に店頭のコピー機で最終プレビューと設定をご確認ください。
